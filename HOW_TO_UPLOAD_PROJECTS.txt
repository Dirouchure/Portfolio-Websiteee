HOW TO UPLOAD PROJECTS - STEP BY STEP GUIDE
============================================

STEP 1: START YOUR SERVERS
---------------------------
1. Open phpMyAdmin and start MySQL (or use XAMPP Control Panel)
2. Open Terminal/Command Prompt in project folder
3. Start Backend:
   cd backend
   node server.js
   
4. Open NEW Terminal/Command Prompt in project folder
5. Start Frontend:
   cd frontend
   npm start

Your browser should open: http://localhost:3000

STEP 2: LOGIN TO ADMIN PANEL
-----------------------------
1. Go to: http://localhost:3000/admin/login
2. Enter credentials:
   Username: admin
   Password: admin123
3. Click "Login"

STEP 3: GO TO MANAGE PROJECTS
------------------------------
1. After login, you'll see Dashboard
2. Click on "Manage Projects" card
3. You'll see the project upload form

STEP 4: FILL PROJECT DETAILS
-----------------------------
Fill in the form with your project information:

REQUIRED FIELDS:
* Project Title - Name of your project (e.g., "My Portfolio Website")

OPTIONAL BUT RECOMMENDED:
* Description - What the project is about
* Category - Type of project (e.g., "Web Development", "Video Editing", "Mobile App")
* Status - Choose one:
  - Completed (project is finished)
  - In Progress (still working on it)
  - Planning (just starting)

* Client Name - If it was for a client (e.g., "ABC Company")
* Duration - How long it took (e.g., "2 months", "3 weeks")
* Start Date - When you started
* End Date - When you finished
* Team Size - Number of people (default is 1 for solo projects)

* Technologies - Programming languages/tools used (separate with commas)
  Example: React, Node.js, MongoDB, CSS

* Key Highlights - Important features (separate with commas)
  Example: Responsive design, Fast loading, SEO optimized

* Tags - Keywords for search (separate with commas)
  Example: responsive, modern, professional

* GitHub URL - Link to your GitHub repository
  Example: https://github.com/yourusername/projectname

* Live Demo URL - Link to live working project
  Example: https://yourproject.com

* Project Website URL - Another project link if needed

* Project Image - Click "Choose File" and select an image
  - Recommended size: 800x600 pixels or larger
  - Formats: JPG, PNG, GIF
  - Max size: 5MB

* Featured Project - Check this box to highlight important projects
  (Featured projects appear first with special styling)

STEP 5: UPLOAD PROJECT IMAGE
-----------------------------
1. Click "Choose File" button next to "Project Image"
2. Browse your computer and select project screenshot/image
3. Recommended: Use clear, high-quality images showing your project

STEP 6: SAVE PROJECT
--------------------
1. Review all information
2. Click "Add Project" button at bottom
3. You'll see "Project added successfully" message
4. Your project appears in the list below

STEP 7: VIEW YOUR PROJECT
--------------------------
1. Open new tab: http://localhost:3000/projects
2. You'll see your uploaded project
3. Click on project card to see full details in popup modal

STEP 8: EDIT OR DELETE PROJECT
-------------------------------
To Edit:
1. Go back to: http://localhost:3000/admin/projects
2. Find your project in the list
3. Click "Edit" button
4. Update any fields you want
5. Click "Update Project"

To Delete:
1. Go to: http://localhost:3000/admin/projects
2. Find your project in the list
3. Click "Delete" button
4. Confirm deletion

TIPS FOR BEST RESULTS:
-----------------------
✓ Use clear project names
✓ Write detailed descriptions
✓ Add high-quality images (recommended: 1200x800px)
✓ List all technologies used
✓ Add working demo links if available
✓ Use "Featured" for your best 2-3 projects
✓ Keep technologies and tags comma-separated
✓ Use proper project categories for filtering

TROUBLESHOOTING:
----------------
Problem: Image not uploading
Solution: Check file size (max 5MB), use JPG/PNG format

Problem: Can't login to admin
Solution: Username: admin, Password: admin123

Problem: Project not showing
Solution: Refresh page, check if backend is running

Problem: Error saving project
Solution: Fill required field (Title), check backend terminal for errors
