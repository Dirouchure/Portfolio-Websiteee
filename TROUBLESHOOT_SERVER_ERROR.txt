TROUBLESHOOTING: "Server Error" on Login

This error means the frontend can't connect to the backend API.

=== STEP-BY-STEP FIX ===

STEP 1: Check MySQL is Running
✓ Open XAMPP Control Panel
✓ Look for MySQL row
✓ Status should show "Running" (green)
✓ If not, click "Start" button

STEP 2: Import Database
✓ Open: http://localhost/phpmyadmin
✓ Check if "portfolio_db" exists in left sidebar
✓ If NOT found:
  - Click "Import" tab
  - Choose file: database/portfolio_db.sql
  - Click "Go"
  - Wait for success message

STEP 3: Check Backend is Running
✓ Open Command Prompt/Terminal
✓ Navigate to backend folder:
  cd C:\Users\hp\Desktop\portfolio-website\backend

✓ Install dependencies (first time only):
  npm install

✓ Start backend server:
  npm start

✓ You should see:
  "Server running on port 5000"

✓ If you see errors:
  - Check MySQL is running in XAMPP
  - Check database "portfolio_db" exists
  - Check backend/.env file exists

STEP 4: Check Frontend is Running
✓ Open NEW Command Prompt/Terminal
✓ Navigate to frontend folder:
  cd C:\Users\hp\Desktop\portfolio-website\frontend

✓ Install dependencies (first time only):
  npm install

✓ Start frontend:
  npm start

✓ Browser should open: http://localhost:3000

STEP 5: Test Login Again
✓ Go to: http://localhost:3000/admin/login
✓ Username: admin
✓ Password: admin123
✓ Click Login

=== COMMON ERRORS AND SOLUTIONS ===

ERROR: "Cannot connect to MySQL"
FIX:
- Start MySQL in XAMPP Control Panel
- Check green "Running" indicator

ERROR: "Database 'portfolio_db' does not exist"
FIX:
- Import database/portfolio_db.sql in phpMyAdmin

ERROR: "Port 5000 already in use"
FIX:
- Stop other programs using port 5000
- Or change PORT in backend/.env

ERROR: "npm not found"
FIX:
- Install Node.js from: https://nodejs.org
- Restart terminal after installation

ERROR: "Server running on port 5000" but still "Server error"
FIX:
- Check if frontend is trying to connect to wrong URL
- Open browser console (F12) and check error messages
- Make sure backend terminal shows no errors

ERROR: "Invalid credentials" (after fixing server error)
FIX:
- Import: database/fix_admin_login.sql in phpMyAdmin
- Try login again: admin / admin123

=== VERIFY EVERYTHING IS WORKING ===

1. XAMPP MySQL: Running (green)
2. phpMyAdmin: http://localhost/phpmyadmin shows portfolio_db
3. Backend Terminal: Shows "Server running on port 5000"
4. Frontend Terminal: Shows "webpack compiled successfully"
5. Browser: http://localhost:3000 loads (even if blank)
6. Backend API: http://localhost:5000/api/profile returns data

=== TEST BACKEND DIRECTLY ===

Open browser and go to:
http://localhost:5000/api/profile

If working, you'll see JSON data like:
{
  "id": 1,
  "full_name": "Your Name",
  "title": "Full Stack Developer",
  ...
}

If you see "Cannot GET" or error:
- Backend is not running properly
- Check backend terminal for errors

=== CHECK BACKEND TERMINAL FOR ERRORS ===

Look for these error messages:

"ECONNREFUSED":
- MySQL not running in XAMPP
- Start MySQL service

"ER_BAD_DB_ERROR":
- Database doesn't exist
- Import portfolio_db.sql

"ER_ACCESS_DENIED_ERROR":
- Wrong database credentials
- Check backend/.env file

"EADDRINUSE":
- Port 5000 already in use
- Close other programs or change port

=== STILL NOT WORKING? ===

Do a complete reset:

1. Stop all servers (Ctrl+C in both terminals)

2. In XAMPP, stop MySQL

3. In phpMyAdmin:
   - Import: database/DROP_DATABASE.sql
   - Import: database/portfolio_db.sql

4. Start MySQL in XAMPP

5. Delete node_modules folders:
   - Delete: backend/node_modules
   - Delete: frontend/node_modules

6. Reinstall everything:
   cd backend
   npm install
   npm start

7. In NEW terminal:
   cd frontend
   npm install
   npm start

8. Try login again
