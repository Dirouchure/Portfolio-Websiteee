FIX LOGIN PROBLEM - STEP BY STEP SOLUTION
==========================================

PROBLEM: "Login failed" error when trying to login

QUICK FIX - TRY THESE FIRST:
-----------------------------

SOLUTION 1: CHECK IF BACKEND IS RUNNING
----------------------------------------
1. Open Terminal/Command Prompt
2. Go to backend folder: cd backend
3. Run: node server.js
4. You should see: "Server running on port 5000"
5. Keep this terminal open!
6. Try login again

If you see errors, go to SOLUTION 4 below.


SOLUTION 2: CHECK DATABASE CONNECTION
--------------------------------------
1. Make sure XAMPP is running
2. MySQL must be started (green in XAMPP)
3. Open phpMyAdmin: http://localhost/phpmyadmin
4. Check if database "portfolio_db" exists on left side
5. If NOT exists, go to SOLUTION 3


SOLUTION 3: IMPORT DATABASE
----------------------------
1. Open phpMyAdmin: http://localhost/phpmyadmin
2. Click "New" button to create database
3. Database name: portfolio_db
4. Click "Create"
5. Click on "portfolio_db" in left sidebar
6. Click "Import" tab at top
7. Click "Choose File"
8. Select: database/portfolio_db.sql
9. Click "Go" at bottom
10. Wait for success message
11. Try login again with:
    Username: admin
    Password: admin123


SOLUTION 4: TEST LOGIN SYSTEM
------------------------------
Run this test script to find exact problem:

1. Open Terminal in backend folder
2. Run: node test_login.js
3. Read the output - it will tell you exactly what's wrong
4. Follow the solution it suggests


SOLUTION 5: RESET ADMIN USER
-----------------------------
If admin user is missing or password wrong:

1. Open phpMyAdmin: http://localhost/phpmyadmin
2. Click "portfolio_db" database on left
3. Click "SQL" tab at top
4. Copy and paste this code:

DELETE FROM admin;
INSERT INTO admin (username, email, password) 
VALUES ('admin', 'admin@portfolio.com', '$2a$10$SNy/R8cXFTSqADV9uIx01OXwg1VuN54xp7JOAa9Ntrar9O6J0UVAW');

5. Click "Go" button
6. You should see "1 row inserted"
7. Now try login:
   Username: admin
   Password: admin123


SOLUTION 6: CHECK BACKEND CONSOLE
----------------------------------
1. Look at the terminal where backend is running
2. When you click "Login", you should see logs
3. If you see errors, check:
   - Database connection error? → Check .env file
   - JWT error? → Check JWT_SECRET in .env
   - Port error? → Another app using port 5000


SOLUTION 7: CHECK FRONTEND API URL
-----------------------------------
1. Open: frontend/src/config/api.js
2. Make sure it says:
   baseURL: 'http://localhost:5000/api'
3. Save file
4. Restart frontend (Ctrl+C and npm start)


SOLUTION 8: CLEAR BROWSER CACHE
--------------------------------
1. Press Ctrl+Shift+Delete (or Cmd+Shift+Delete on Mac)
2. Clear "Cached images and files"
3. Close browser completely
4. Open browser again
5. Go to: http://localhost:3000/admin/login
6. Try login again


SOLUTION 9: CHECK .ENV FILE
----------------------------
1. Open: backend/.env
2. Make sure it has:

PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=portfolio_db
JWT_SECRET=your_jwt_secret_key_change_this_in_production

3. Save file
4. Restart backend


SOLUTION 10: COMPLETE RESET
----------------------------
If nothing works, do complete reset:

1. Stop all servers (Ctrl+C in terminals)

2. Reset Database:
   - Open phpMyAdmin
   - Click "portfolio_db"
   - Click "Operations" tab
   - Click "Drop the database" at bottom
   - Confirm deletion
   - Create new database "portfolio_db"
   - Import database/portfolio_db.sql

3. Restart Backend:
   cd backend
   node server.js

4. Restart Frontend:
   cd frontend
   npm start

5. Try login:
   Username: admin
   Password: admin123


COMMON MISTAKES:
----------------
✗ MySQL not running in XAMPP
✗ Backend not started
✗ Database not imported
✗ Wrong username (must be: admin)
✗ Wrong password (must be: admin123)
✗ Typing spaces before/after username or password
✗ Port 5000 already in use by another app


CORRECT LOGIN CREDENTIALS:
---------------------------
Username: admin
Password: admin123

(Both are lowercase, no spaces!)


HOW TO CHECK IF IT'S WORKING:
------------------------------
1. Backend terminal should show: "Server running on port 5000"
2. No errors in backend terminal
3. Database "portfolio_db" exists in phpMyAdmin
4. Table "admin" has 1 row with username "admin"
5. Frontend opens at: http://localhost:3000
6. Login page at: http://localhost:3000/admin/login


STILL NOT WORKING?
------------------
Run the test script to diagnose:

1. Open Terminal

4. Read output and follow instructions

The test will tell you exactly what's wrong!
