HOW TO PUSH PORTFOLIO TO GITHUB
================================

STEP 1: CREATE .gitignore FILE
-------------------------------
First, we need to ignore sensitive files and node_modules.

This is IMPORTANT to protect your passwords!


STEP 2: INITIALIZE GIT
-----------------------
Open Command Prompt in your portfolio folder:

cd C:\Users\hp\Desktop\portfolio-website

Then run these commands one by one:

git init
git add .
git commit -m "Initial commit: Professional Portfolio Website"


STEP 3: CREATE GITHUB REPOSITORY
---------------------------------
1. Go to: https://github.com
2. Click the "+" icon (top right)
3. Click "New repository"
4. Repository name: portfolio-website
5. Description: Professional Portfolio Website with Admin Panel
6. Choose: Public (or Private if you want)
7. DON'T check "Initialize with README"
8. Click "Create repository"


STEP 4: CONNECT TO GITHUB
--------------------------
GitHub will show you commands. Use these:

git remote add origin https://github.com/YOUR_USERNAME/portfolio-website.git
git branch -M main
git push -u origin main

REPLACE "YOUR_USERNAME" with your actual GitHub username!


STEP 5: ENTER CREDENTIALS
--------------------------
When prompted:
- Username: Your GitHub username
- Password: Use Personal Access Token (not your password!)

To create token:
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Give it a name: "Portfolio Upload"
4. Check: "repo" (full control)
5. Click "Generate token"
6. Copy the token (starts with ghp_...)
7. Use this as password when pushing


COMPLETE COMMAND SEQUENCE
--------------------------
cd C:\Users\hp\Desktop\portfolio-website
git init
git add .
git commit -m "Initial commit: Professional Portfolio Website"
git remote add origin https://github.com/YOUR_USERNAME/portfolio-website.git
git branch -M main
git push -u origin main


FUTURE UPDATES
--------------
After making changes, run:

git add .
git commit -m "Updated portfolio"
git push


IMPORTANT NOTES
---------------
✓ .gitignore will protect your .env file (passwords)
✓ node_modules will NOT be uploaded (too large)
✓ Database passwords are NOT uploaded
✓ Anyone can download and install from GitHub

SECURITY
--------
Your .env file with database password is PROTECTED by .gitignore!
Others will need to create their own .env file.
