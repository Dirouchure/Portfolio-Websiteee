DATABASE IMPORT ORDER

Follow this exact order when setting up the database:

STEP 1: Import Main Database Schema
File: portfolio_db.sql
This creates:
- Database structure (8 tables)
- Default admin account (username: admin, password: admin123)
- Default profile entry

STEP 2 (Optional): Import Sample Data
File: sample_data.sql
This adds:
- 12 sample skills
- 2 education entries
- 2 work experiences
- 4 sample projects
- 4 certificates

Note: Skip Step 2 if you want to start with empty tables and add your own data through the admin panel.

RESET DATABASE:
If you need to start over:
1. Import DROP_DATABASE.sql
2. Import portfolio_db.sql
3. (Optional) Import sample_data.sql
