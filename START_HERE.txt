=== 3-STEP QUICK START ===

STEP 1: Setup Database (1 minute)
1. Open XAMPP Control Panel
2. Click "Start" next to MySQL
3. Open: http://localhost/phpmyadmin
4. Click "Import" → Choose: database/portfolio_db.sql
5. Click "Go"

STEP 2: Start Servers (30 seconds)
Just double-click: SETUP_AND_START.bat
(Everything starts automatically!)

STEP 3: Login & Add Your Info (10 minutes)
1. Browser opens at http://localhost:3000
2. Go to: /admin/login
3. Login: admin / admin123
4. Upload your photo
5. Update your profile
6. Add your projects (videos)

DONE! 🎉

=== TROUBLESHOOTING ===

Problem: Can't login / Server Error
Fix: Run SETUP_AND_START.bat

Problem: Invalid credentials
Fix: In phpMyAdmin, run:
      database/fix_admin_login.sql

Problem: Images not showing
Fix: Make sure backend is running

Problem: Website not loading
Fix: Check XAMPP MySQL is started
