HOW TO CHECK ALL CONNECTIONS

=== QUICK TEST - Use Batch File ===

1. Double-click: CHECK_CONNECTIONS.bat

This will automatically check:
- Node.js installed
- MySQL running
- Database connection
- Frontend configuration

=== MANUAL TEST ===

TEST 1: Check MySQL is Running
1. Open XAMPP Control Panel
2. MySQL should show "Running" (green)
3. If not, click "Start"

TEST 2: Check Database Exists
1. Open: http://localhost/phpmyadmin
2. Look for "portfolio_db" in left sidebar
3. Click on it
4. Should see 8 tables: admin, profile, skills, etc.

TEST 3: Test Backend Database Connection
1. Open Command Prompt
2. Run:
   cd C:\Users\hp\Desktop\portfolio-website\backend
   node test_connection.js

You should see:
✓ Database connection successful!
✓ Found 8 tables
✓ Admin account found
✓ Profile found

If you see errors:
- MySQL not running → Start in XAMPP
- Database not found → Import portfolio_db.sql
- Wrong credentials → Check backend/.env

TEST 4: Test Backend Server
1. Start backend:
   cd backend
   npm start

2. Should see: "Server running on port 5000"
3. No error messages

TEST 5: Test Backend API
1. Open browser
2. Go to: http://localhost:5000/api/profile

Should see JSON data:
{
  "id": 1,
  "full_name": "Your Name",
  "title": "Full Stack Developer",
  ...
}

If you see:
- "Cannot GET" → Backend not running
- Error message → Check backend terminal
- Nothing loads → Check URL is correct

TEST 6: Test Frontend Configuration
1. Open file: frontend/src/config/api.js
2. Should see: const API_URL = 'http://localhost:5000/api';
3. If different, change it

TEST 7: Test Frontend Connection
1. Start frontend:
   cd frontend
   npm start

2. Browser opens at: http://localhost:3000
3. Open browser console (F12)
4. Go to: http://localhost:3000/admin/login
5. Check console for errors

If you see:
- "Network Error" → Backend not running
- "ERR_CONNECTION_REFUSED" → Backend not started
- No errors → Connection working!

TEST 8: Test Complete Flow
1. XAMPP MySQL: Running ✓
2. Backend terminal: "Server running on port 5000" ✓
3. Frontend loads: http://localhost:3000 ✓
4. Can login: admin / admin123 ✓

Layer 4: Communication
- Backend can query database

Test: Login and check browser console

=== COMMON CONNECTION ISSUES ===

Issue: "Cannot connect to database"
Check:
- MySQL running in XAMPP
- Database exists in phpMyAdmin
- Credentials correct in backend/.env

Issue: "Network Error" on login
Check:
- Backend server running
- Port 5000 not blocked
- Backend terminal shows no errors

Issue: "CORS Error"
Check:
- Backend has cors() enabled
- Frontend API URL correct
- Backend started before frontend

Issue: "Server Error"
Check:
- Backend can connect to database
- Run: node test_connection.js
- Check backend terminal for errors
