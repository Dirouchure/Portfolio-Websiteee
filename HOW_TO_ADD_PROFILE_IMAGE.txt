HOW TO ADD YOUR PROFILE IMAGE

=== METHOD 1: Using Admin Panel (EASIEST) ===

STEP 1: Prepare Your Image
1. Choose your profile photo
2. Recommended size: 500x500 pixels or square format
3. Format: JPG, PNG, or GIF
4. File size: Less than 5MB

STEP 2: Start the Application
1. Open Terminal in backend folder
   - Run: npm start
   - Should show: "Server running on port 5000"

2. Open NEW Terminal in frontend folder
   - Run: npm start
   - Browser opens at: http://localhost:3000

STEP 3: Login to Admin Panel
1. Go to: http://localhost:3000/admin/login
2. Username: admin
3. Password: admin123
4. Click "Login"

STEP 4: Upload Profile Image
1. After login, you'll see Dashboard
2. Click on "Manage Profile" card
3. Scroll down to "Upload Profile Image" section
4. Click "Choose File" button
5. Select your profile photo from your computer
6. Image will upload automatically
7. You'll see "Image uploaded successfully" message

STEP 5: Verify Image on Website
1. Click "View Website" in dashboard OR
2. Open new tab: http://localhost:3000
3. Your profile image now shows on:
   - Home page (right side)
   - About page (left sidebar)

DONE! ✓

=== METHOD 2: Manual Upload (Alternative) ===

If admin panel doesn't work, manually copy image:

STEP 1: Prepare Image
1. Rename your image to something simple: profile.jpg
2. Make sure it's JPG, PNG, or GIF format

STEP 2: Copy to Uploads Folder
1. Copy your image file
2. Navigate to: C:\Users\hp\Desktop\portfolio-website\backend\uploads
3. Paste the image there
4. Note the exact filename (e.g., profile.jpg)

STEP 3: Update Database
1. Open phpMyAdmin: http://localhost/phpmyadmin
2. Select "portfolio_db" database
3. Click "profile" table
4. Click "Edit" (pencil icon) on the row
5. Find "profile_image" field
6. Enter your filename: profile.jpg
7. Click "Go" to save

STEP 4: Restart Backend Server
1. Stop backend (Ctrl+C in backend terminal)
2. Start again: npm start

STEP 5: Refresh Website
1. Go to: http://localhost:3000
2. Refresh page (F5)
3. Your image should now appear!

=== IMAGE SPECIFICATIONS ===

Recommended:
- Size: 500x500 pixels (square)
- Format: JPG or PNG
- File size: Under 5MB (smaller is better for loading speed)
- Background: Solid color or professional background

For Best Results:
- Use professional headshot
- Good lighting
- Face clearly visible
- Centered composition
- High quality (not blurry)

=== TROUBLESHOOTING ===

Image Not Showing:
1. Check filename has no spaces
2. Check file is in backend/uploads folder
3. Check backend server is running
4. Check browser console for errors (F12)
5. Hard refresh page (Ctrl+Shift+R)

"Choose File" Button Not Working:
1. Make sure you're logged into admin panel
2. Check browser console for errors
3. Try different browser
4. Make sure backend server is running

Upload Fails:
1. Check image size (must be under 5MB)
2. Check file format (JPG, PNG, GIF only)
3. Check backend/uploads folder exists
4. Check backend terminal for error messages

Image Too Large/Small:
- Browser automatically sizes image
- CSS handles responsive sizing
- Original file can be any size (recommended 500x500)

Image Path Issues:
- Image URL should be: http://localhost:5000/uploads/yourimage.jpg
- Test by opening this URL directly in browser
- If "Cannot GET", check filename and location
