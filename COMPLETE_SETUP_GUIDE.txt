=== HOW TO ADD YOUR CONTENT ===

1. ADD PROFILE PHOTO:
   - Login to admin panel
   - Click "Manage Profile"
   - Scroll to "Upload Profile Image"
   - Choose your photo
   - Done!

2. UPDATE PROFILE INFO:
   - In "Manage Profile"
   - Update: Name, Title, Bio, Email, Phone
   - Click "Update Profile"

3. ADD SKILLS:
   - Click "Manage Skills"
   - Fill form: Skill name, Category, Proficiency
   - Click "Add Skill"
   - Repeat for all skills

4. ADD PROJECTS:
   - Click "Manage Projects"
   - Fill form: Title, Description, Tech
   - Upload project image
   - Add GitHub/Live URL
   - Click "Add Project"

5. ADD EDUCATION:
   - Click "Manage Education"
   - Fill form: School, Degree, Years
   - Click "Add Education"

6. ADD EXPERIENCE:
   - Click "Manage Experience"
   - Fill form: Company, Position, Dates
   - Check "Currently working" if active
   - Click "Add Experience"

7. ADD CERTIFICATES:
   - Click "Manage Certificates"
   - Fill form: Title, Organization, Date
   - Upload certificate image
   - Click "Add Certificate"

=== TROUBLESHOOTING ===

Problem: Login shows "Server Error"
Solution: Backend not running
Fix: Double-click START_BACKEND.bat

Problem: Login shows "Invalid credentials"
Solution: Wrong password in database
Fix: Run fix_admin_login.sql in phpMyAdmin

Problem: Website doesn't load
Solution: Servers not started
Fix: Double-click SETUP_AND_START.bat

Problem: Images not showing
Solution: Backend not running or wrong URL
Fix: Check backend terminal for errors

Problem: Can't upload images
Solution: Uploads folder missing or no permissions
Fix: Create backend/uploads folder

Problem: Database errors
Solution: MySQL not running or database doesn't exist
Fix: 
1. Start MySQL in XAMPP
2. Import database/portfolio_db.sql

=== DEPLOYING TO PRODUCTION ===

When ready to go live:

1. Get hosting:
   - Frontend: Vercel, Netlify (free)
   - Backend: Heroku, Railway (free tier)
   - Database: Railway, PlanetScale (free)

2. Update configuration:
   - Change API_URL in frontend/src/config/api.js
   - Update CORS in backend/server.js
   - Change JWT_SECRET in .env
   - Update database credentials

3. Build frontend:
   cd frontend
   npm run build

4. Deploy!
