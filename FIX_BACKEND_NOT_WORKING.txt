FIX: Backend Not Working (http://localhost:5000/api/profile)

=== PROBLEM ===
Backend server is not running, so the URL doesn't work.

=== EASY SOLUTION - ONE-CLICK SETUP ===

Just double-click this file:
>> SETUP_AND_START.bat

This will automatically:
1. Check Node.js is installed
2. Check MySQL is running
3. Install all dependencies
4. Test database connection
5. Start backend server
6. Start frontend (automatically after 10 seconds)
7. Open browser

DONE! Everything will work!

=== MANUAL SOLUTION ===

If the batch file doesn't work, follow these steps:

STEP 1: Install Dependencies
Open Command Prompt/PowerShell and run:

cd C:\Users\hp\Desktop\portfolio-website\backend
npm install

Wait for installation to complete (may take 2-5 minutes)

STEP 2: Make Sure MySQL is Running
1. Open XAMPP Control Panel
2. Click "Start" next to MySQL
3. Wait for green "Running" status

STEP 3: Make Sure Database Exists
1. Open: http://localhost/phpmyadmin
2. Check if "portfolio_db" exists on left side
3. If NOT, import: database/portfolio_db.sql

STEP 4: Start Backend Server
In the same Command Prompt:

npm start

You should see: "Server running on port 5000"

STEP 5: Test Backend
Open browser: http://localhost:5000/api/profile

Should show JSON data like:
{
  "id": 1,
  "full_name": "Your Name",
  ...
}

STEP 6: Start Frontend (NEW Terminal)
Open NEW Command Prompt:

cd C:\Users\hp\Desktop\portfolio-website\frontend
npm install
npm start

Browser opens at: http://localhost:3000

=== TROUBLESHOOTING ===

ERROR: "npm" is not recognized
FIX: Install Node.js from https://nodejs.org
     Restart terminal after installation

ERROR: Port 5000 already in use
FIX: Close other programs using port 5000
     Or restart computer

ERROR: Cannot connect to MySQL
FIX: Start MySQL in XAMPP Control Panel
     Wait for green "Running" status

ERROR: Database does not exist
FIX: Import database/portfolio_db.sql in phpMyAdmin

ERROR: npm install fails
FIX: Delete node_modules folder
     Run npm install again
     Make sure you have internet connection
