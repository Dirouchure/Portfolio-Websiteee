=== TECHNOLOGY STACK ===

Backend:
- Node.js & Express.js
- MySQL (via XAMPP)
- JWT for authentication
- bcryptjs for password hashing
- Multer for file uploads
- express-validator for input validation

Frontend:
- React 18
- React Router for navigation
- Axios for API calls
- React Icons for UI icons
- CSS for styling (responsive design)

=== FILE CONNECTIONS ===

Backend to Database:
- backend/config/db.js → MySQL connection
- backend/.env → Database credentials
- database/portfolio_db.sql → Database schema

Frontend to Backend:
- frontend/src/config/api.js → Backend API URL (http://localhost:5000)
- All API calls use Axios with JWT token

Backend Routes:
- backend/server.js imports all route files
- All routes connected under /api prefix
- Protected routes use auth middleware

Frontend Routing:
- frontend/src/App.js defines all routes
- Public routes accessible to all
- Admin routes protected by ProtectedRoute component

File Uploads:
- Uploaded to: backend/uploads/
- Accessible via: http://localhost:5000/uploads/[filename]
- Used by: profile images, project images, certificates, resumes

=== PORT CONFIGURATION ===

Backend:  http://localhost:5000
Frontend: http://localhost:3000
MySQL:    localhost:3306
phpMyAdmin: http://localhost/phpmyadmin

=== ENVIRONMENT VARIABLES ===

Backend (.env):
- PORT: Server port
- DB_HOST: MySQL host
- DB_USER: MySQL username
- DB_PASSWORD: MySQL password
- DB_NAME: Database name
- JWT_SECRET: Secret key for JWT tokens

Frontend:
- API URL configured in: src/config/api.js
- Default: http://localhost:5000/api
