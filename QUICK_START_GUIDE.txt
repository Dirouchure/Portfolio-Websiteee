QUICK START GUIDE - GET YOUR PORTFOLIO RUNNING IN 5 MINUTES

=== STEP 1: Setup Database (2 minutes) ===

1. Start XAMPP
   - Open XAMPP Control Panel
   - Click "Start" for MySQL
   - Wait for green indicator

2. Import Database
   - Open browser: http://localhost/phpmyadmin
   - Click "Import" tab
   - Click "Choose File"
   - Select: C:\Users\hp\Desktop\portfolio-website\database\portfolio_db.sql
   - Click "Go" button
   - Wait for "Import has been successfully finished"

=== STEP 2: Install Dependencies (2 minutes) ===

1. Open Terminal/Command Prompt

2. Install Backend Dependencies:
   cd C:\Users\hp\Desktop\portfolio-website\backend
   npm install
   (Wait for installation to complete)

3. Install Frontend Dependencies (in NEW terminal):
   cd C:\Users\hp\Desktop\portfolio-website\frontend
   npm install
   (Wait for installation to complete)

=== STEP 3: Start Application (1 minute) ===

1. Start Backend Server:
   (In backend terminal)
   npm start
   Should show: "Server running on port 5000"

2. Start Frontend Server:
   (In frontend terminal)
   npm start
   Browser automatically opens: http://localhost:3000

=== STEP 4: Login & Add Your Profile Image ===

1. Login to Admin Panel:
   - Browser opens at: http://localhost:3000
   - Click on navigation and go to: http://localhost:3000/admin/login
   - Username: admin
   - Password: admin123
   - Click "Login"

2. Upload Your Profile Photo:
   - Click "Manage Profile" card
   - Scroll down to "Upload Profile Image"
   - Click "Choose File"
   - Select your photo (JPG, PNG)
   - Wait for "Image uploaded successfully"

3. View Your Website:
   - Go to: http://localhost:3000
   - See your photo on Home page!

=== STEP 5: Customize Your Profile ===

In Admin Panel:

1. Update Profile Information:
   - Click "Manage Profile"
   - Update: Name, Title, Bio, Email, Phone
   - Click "Update Profile"

2. Add Your Skills:
   - Click "Manage Skills"
   - Add video editing skills (Premiere Pro, After Effects, etc.)
   - Set proficiency levels

3. Add Your Projects:
   - Click "Manage Projects"
   - Add video projects
   - Upload thumbnails
   - Add YouTube/Vimeo links

=== TROUBLESHOOTING ===

Backend won't start:
- Make sure port 5000 is not in use
- Check backend/.env file exists
- Make sure MySQL is running in XAMPP

Frontend won't start:
- Make sure port 3000 is not in use
- Delete node_modules and run npm install again

Can't login:
- Run: database/fix_admin_login.sql in phpMyAdmin
- Use: admin / admin123

Image not showing:
- Make sure backend server is running
- Check browser console (F12) for errors
- Check image is in backend/uploads folder
- Refresh page (Ctrl+Shift+R)

Database error:
- Make sure MySQL is running in XAMPP
- Check database name is "portfolio_db"
- Check backend/.env has correct credentials
